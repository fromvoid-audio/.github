# FromVoid

I’m [PORTALSURFER](https://soundcloud.com/portalsurfer). I make music and build instruments and tools for making it. I share them here as open-source software.

I put a lot of my own time and money into these projects. I use AI extensively to build them and make them more accessible. I want everyone to be able to play, express themselves, and make music, whatever their budget.

If you’d like to help, I’d love your code contributions. You can also chip in on Ko-fi to help cover the costs. Thank you for your support. I really appreciate it.
